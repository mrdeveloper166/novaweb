# 🚀 NovaWeb - IT Company Website

NovaWeb is a modern and responsive IT company website developed using PHP. The website presents technology services, company information, projects, and contact details through a clean and professional interface.

## ✨ Features

* Modern and responsive design
* IT company services showcase
* About Company section
* Services and solutions
* Portfolio / Projects section
* Contact form
* Responsive navigation
* Mobile-friendly layout
* Clean and professional UI
* PHP-based dynamic pages

## 🛠️ Technologies Used

* PHP
* HTML5
* CSS3
* JavaScript
* Bootstrap
* MySQL

## 📌 Services Showcase

The website can be used to present services such as:

* Web Development
* Software Development
* Mobile App Development
* Custom PHP Development
* IT Consulting
* Digital Solutions
* Website Maintenance

## ⚙️ Installation

Clone the repository:

```bash
git clone https://github.com/mrdeveloper166/novaweb.git
```

Move the project folder into your XAMPP `htdocs` directory.

Start **Apache** and **MySQL** from XAMPP.

If the project uses a database, import the provided SQL file into phpMyAdmin and update the database connection settings.

Open the website:

```text
http://localhost/novaweb/
```
